# ADR-001 技术栈决策（openvpn-wm）

- **状态**: ✅ 已拍板
- **日期**: 2026-09-03
- **决策人**: 用户

---

## 1. Web 管理端

| 层 | **决定** | 理由 |
|---|---|---|
| 后端 | **FastAPI**（Python 3.10+） | 环境已有 python3；与 easyrsa/shell 脚本 subprocess 交互天然顺手；自动生成 OpenAPI 文档；异步适合轮询 status.log |
| ORM | **SQLAlchemy 2.x** + Alembic 迁移 | 第一期 SQLite，后期换 Postgres 零改代码 |
| DB | **SQLite**（第一期）→ **PostgreSQL**（多节点/收款上量后） | 单机零运维起步 |
| 前端 | **Vue 3 + Vite + Element Plus** | 表格/表单/后台管理场景最成熟，组件齐 |
| 图表 | ECharts | Dashboard 用 |
| 认证 | JWT(access+refresh) + **TOTP 2FA**(pyotp) | 面板能签发 VPN 账号，必须强认证 |
| 密码哈希 | **argon2**(argon2-cffi) | 优于 bcrypt |
| 部署 | uvicorn + **nginx** 反代 + **HTTPS 强制** | 面板绝不允许裸 HTTP |
| 进程管理 | systemd | 与服务端一致 |

### 强制约束（安全）
- 所有传给 subprocess 的参数**必须白名单校验**（用户名 `^[a-zA-Z0-9_-]{3,32}$`）
- **禁止 `shell=True`**，一律 `subprocess.run([...])` 列表形式
- `.ovpn` **不落盘**，一次性下载令牌（5 分钟）
- 本面板**不含任何支付功能**（支付在 `openvpn-game`，独立部署独立库）

---

## 2. 客户端（三种方案通用）

| 平台 | **决定** |
|---|---|
| macOS | **shell 安装器 + 系统 openvpn(brew) + pf anchor** |
| Windows | **PowerShell 安装器 + OpenVPN GUI/官方客户端 + netsh/WFP** |
| Linux | **shell 安装器 + openvpn + nftables/ipset** |
| iKuai | 直接导入 `.ovpn`（仅支持 ③ `game-open`，路由器侧不做 kill-switch） |

> 本项目**不自研 GUI 客户端**（用系统/官方 OpenVPN 客户端 + 安装脚本）。
> 自研 GUI 客户端在 `openvpn-game` 项目（那边需要收款界面 + 零门槛体验）。

---

## 3. 服务端

| 项 | **决定** |
|---|---|
| OS | **Ubuntu 22.04 / 24.04 LTS** |
| VPN | **OpenVPN 2.6+**（社区版） |
| DNS 分流 | **dnsmasq** |
| DNS 加密上游 | **stubby**（DoT）→ 1.1.1.1:853 / 8.8.8.8:853 / 9.9.9.9:853 |
| 防火墙 | **iptables + ipset**（用独立自定义链，保证幂等） |
| PKI | **easy-rsa 3** |
| 进程管理 | systemd |
