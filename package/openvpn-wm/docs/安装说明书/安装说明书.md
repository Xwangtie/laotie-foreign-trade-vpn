# 老铁外贸网络管理系统 安装说明书

版本：2026-09-06

这份说明书写给负责部署和维护的人员。你需要在全新的海外 Linux 服务器上安装整套系统，包括 VPN 服务端、DNS 防污染服务和 Web 管理后台。安装前请先读完全文，再按步骤执行。

安装完成后，管理后台地址、客户账号密码等由部署者自行保管，不要写在对外展示的资料里。

---

## 1. 系统包含什么

安装包包含三部分：

1. OpenVPN 服务端。提供三种网络方案，签发客户证书，并管理在线客户。
2. DNS 防污染服务。使用加密 DNS 上游，为外贸客户提供稳定解析。
3. Web 管理后台。用于开户、续期、吊销、流量统计、端口映射、域名封锁、VLAN 互访等日常操作。

同一套源码既可用于第一台服务器，也保留后续增加第二台服务器的结构。

---

## 2. 服务器准备

### 2.1 服务器要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Ubuntu 22.04、Ubuntu 24.04 或 Debian 12 |
| 配置 | 建议 2 核 CPU、2 GB 内存、20 GB 硬盘以上 |
| 公网 IP | 独立公网 IPv4 |
| 域名 | 一个可用域名，A 记录指向服务器公网 IP，例如 vpn.你的域名.com |
| 权限 | root 用户或可执行 sudo 的账户 |

### 2.2 开放端口

安装脚本会自动配置防火墙，只放行以下端口：

| 用途 | 协议和端口 |
|---|---|
| SSH 管理 | TCP 22（默认，可按需修改） |
| 网站后台 | TCP 80、443 |
| VPN 客户端接入 | UDP 1194（默认，可按需修改） |

如果服务器厂商控制面板（云安全组）里也有限制，需要在面板中同步放行上述端口。

### 2.3 域名解析

把用于后台访问的域名 A 记录解析到服务器公网 IP，并等待解析生效后再安装。安装时把该域名填写到 DOMAIN 参数中。

## 4. 安装新服务器

以下步骤在服务器上以 root 执行。

### 4.1 上传并解压

把 openvpn-wm-source-20260906.tar.gz 上传到服务器后执行：

```bash
cd /root
mkdir -p /root/openvpn-wm-package
tar -xzf openvpn-wm-source-20260906.tar.gz -C /root/openvpn-wm-package
cd /root/openvpn-wm-package
```

### 4.2 一键安装

执行前先确认下面的变量：

| 变量 | 说明 |
|---|---|
| DOMAIN | 后台访问域名，例如 vpn.你的域名.com |
| PUBLIC_IP | 服务器公网 IP |
| SSH_PORT | SSH 端口，默认 22 |
| VPN_PORT | VPN 端口，默认 1194 |
| PANEL_ADMIN_PASSWORD | 后台初始管理员密码，务必改成强密码 |
| REPLACE_OLD_OPENVPN | 服务器上有旧 OpenVPN 要清除时设为 1 |

示例：

```bash
DOMAIN=vpn.你的域名.com \
PUBLIC_IP=1.2.3.4 \
SSH_PORT=22 \
VPN_PORT=1194 \
PANEL_ADMIN_PASSWORD=请改成强密码 \
AUTO_HTTPS=1 \
bash deploy/install-new-server.sh
```

如果你的服务器以前安装过其他 OpenVPN，并且已经备份过原配置，可加上：

```bash
REPLACE_OLD_OPENVPN=1
```

安装脚本会自动完成以下工作：

- 安装 OpenVPN、EasyRSA、DNS、Nginx、Python 等依赖；
- 生成 CA 与服务器证书（证书默认长期有效）；
- 写入三种方案的 profile；
- 配置防火墙与 DNS 防污染；
- 部署 Web 管理后台；
- 申请 HTTPS 证书；
- 创建初始管理员账号；
- 启动全部服务。

安装成功后会显示 OpenVPN、DNS、面板等服务状态均为 active。

## 5. 安装后确认

### 5.1 登录后台

浏览器打开：

```text
https://你的域名
```

初始管理员用户名：admin

初始管理员密码：安装时 PANEL_ADMIN_PASSWORD 设置的值。如果没有设置该变量，则为 admin。

第一次登录后请立即修改管理员密码。不要把默认密码继续留用。

### 5.2 检查服务

在服务器执行：

```bash
systemctl status openvpn@server openvpnwm-panel nginx dnsmasq
```

应看到 openvpn@server、openvpnwm-panel、nginx、dnsmasq 都处于 active。

### 5.3 开户测试

在后台“客户账号”页新建一个客户：

- 填写客户用户名、姓名、联系电话、公司名称；
- 选择三种方案之一；
- 设置到期时间和流量上限；
- 点击开户，下载 .ovpn 配置文件。

把配置文件导入 OpenVPN 客户端，确认能连接、能正常访问目标网站后再正式发给客户。

## 6. 常用维护说明

### 6.1 客户开通

后台左侧“客户账号”提供开户、修改、续期、暂停、恢复、吊销、删除和下载配置等操作。

### 6.2 VLAN 局域网互访

后台左侧“VLAN设置”：

- “全部互访”总开关默认关闭；
- 可在“分组互访1”和“分组互访2”中把客户加入分组；
- 同组客户可互访，两组互相隔离；
- 加入分组的客户自动分配固定隧道 IP（10.8.0.201 至 10.8.0.250）；
- 客户断开重连一次后固定地址生效。

### 6.3 到期与吊销

- 开户默认有效期为 1 个月；
- 到期后系统自动标记并断开在线连接；
- 吊销后证书无法恢复，只能重新开户；
- 删除客户前必须先吊销。

### 6.4 日志与审计

后台“连接日志”可查看客户连接记录、隧道 IP、流量和认证结果；“审计日志”记录所有后台操作。不要把后台审计日志随意分享给外部人员。

## 7. 备份与恢复

### 7.1 日常备份

建议每天备份以下内容：

```bash
/opt/openvpn-wm/web-panel
/etc/openvpn
/var/lib/openvpn-wm/panel.db
```

其中 /etc/openvpn 内含 CA 和客户证书私钥，是最重要的数据。证书一旦丢失，所有客户都需要重新开户。

### 7.2 使用交付备份恢复

交付目录中的 openvpn-wm-full-backup-20260906.tar.gz 是已运行系统的完整快照。恢复时：

1. 停止面板服务：

```bash
systemctl stop openvpnwm-panel
```

2. 把快照中的 web-panel 解压回 /opt/openvpn-wm/，把 /etc/openvpn 下的内容解压回 /etc/openvpn/。
3. 把 panel.db.20260906 放回 /var/lib/openvpn-wm/panel.db。
4. 设置属主并启动服务：

```bash
chown -R openvpnwm:openvpnwm /opt/openvpn-wm /var/lib/openvpn-wm
systemctl start openvpnwm-panel
systemctl restart openvpn@server
```

恢复完成后，用原管理员账号登录后台验证客户、配置和流量数据。

## 8. 安全注意事项

1. 后台实际域名是部署者的内部信息，不要在对外说明书、客户资料或宣传材料中公开。
2. 安装后立即修改初始管理员密码。
3. 客户证书等于登录凭证，只通过一次性下载链接发给客户本人。
4. 账号到期、暂停、吊销后系统会自动断开连接。
5. 端口映射会把客户内网服务暴露到公网，只对需要远程使用的客户开启。
6. 数据库和 /etc/openvpn 必须异地备份。

## 9. 遇到问题怎么办

先检查以下几项：

1. 客户端无法导入配置：更新到新版 OpenVPN 客户端再试。
2. 客户连接被拒：在后台查看客户状态，是否到期、暂停或吊销。
3. 后台无法访问：检查 80、443 端口是否被服务器厂商安全组拦截。
4. VPN 无法连接：检查 UDP 1194 端口是否放行。
5. 域名证书异常：确认域名解析正确，等待 5 到 10 分钟后再刷新。
