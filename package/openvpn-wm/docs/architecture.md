## 数据流

```
1. 应用发起连接 (e.g. curl https://chatgpt.com)
2. glibc getaddrinfo → /etc/resolv.conf → 127.0.0.1
3. smartdns 查询:
   - chatgpt.com 在国内域名列表? 否
   - 走 DoH 1.1.1.1 → 返回真实 IP (104.18.x.x)
4. 应用连接 104.18.x.x:443
5. 路由表查 104.18.0.0/16:
   - 不在 cn-ipv4.txt
   - 不在 private-ranges.txt
   - 匹配默认路由 (VPN)
6. 走 utun0 → OpenVPN 隧道 → VPS → 互联网
7. 1.1.1.1 在 pf 不被拦截（443 是 HTTPS）
8. chatgpt.com 拿到干净的解析、干净的 TCP 连接、干净的 IP
```
